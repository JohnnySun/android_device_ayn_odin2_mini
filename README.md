# android_device_ayn_odin2_mini

Lineage/AOSP device tree seed for AYN Odin2 Mini.

Source tree path: `device/ayn/odin2_mini`

This branch is intentionally a bring-up seed. It records the observed stock
baseline and provides the first files needed by `repo sync`, blob extraction,
and product wiring. It is not yet a bootable device tree.

Observed stock baseline:

- Model: `Odin2_Mini`
- Device/product: `kalama`
- SoC: `QCS8550`
- Stock Android: 13 / API 33
- Stock kernel: `5.15.123-android13-8-g55ff82ab20b6`
- Treble: true
- Virtual A/B: true

Workbench: `JohnnySun/odin2-mini`
